Figure 3 分组：无干扰条件下，扩展时延对算法影响
==================================================

用途
----
用于生成“固定 0 额外频偏、固定 10 dB SNR、无对向列车干扰，
扫描不同扩展时延”的这一组图。

建议主脚本
----------
ExperimentD_PairedZC_V13_7_TDLD_CoarseFine_Validation.m

推荐配置修改
------------
1. 保持高速铁路模型不变；
2. 无干扰（即使用 V13.7，而不是 V13.8）；
3. 固定 CFO 为几何 Doppler，对应 0 额外频偏：
       cfg.CFOList_Hz = cfg.geometryDoppler_Hz;
4. 固定信噪比：
       cfg.snrList_dB = 10;
5. 扩展时延测试点建议按你当前已有论文/实验点从小到大排列：
       cfg.delayList_effSamples = [0, 0.4, 4, 17.460638];

推荐输出图
----------
1. 扩展时延 vs 粗估计时延 RMSE
2. 扩展时延 vs 精估计首径时延 RMSE
3. 真值时延 vs 估计时延散点图
4. 如需要，可补充扩展时延变化下的 CFO RMSE 曲线

建议论文表述
------------
这一组图的作用，是说明在固定频偏和固定信噪比下，不同传播/扩展时延条件会如何影响接收机性能。

说明
----
本压缩包沿用 V13.7 的无干扰粗精联合接收机，方便你单独做 delay 扫描图。
